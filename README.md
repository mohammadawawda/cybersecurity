# Cybersecurity

Privacy and security projects: oblivious RAM and an anonymous messaging network.

* [path_oram](path_oram) Path ORAM client and server with encryption and integrity checks.
* [mixnet](mixnet) a Chaum style mix network in Go with onion encryption, gRPC over TLS and Docker.
* [crash_safe_oram](crash_safe_oram) Path ORAM that recovers from client crashes with a write ahead log.
